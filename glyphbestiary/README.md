# 字兽录 · glyphbestiary

> 一个手绘的字会长成一个**物种**，而不是收敛成一个答案。

<p align="center"><i>第一步：骨架 · 渲染 · 手抖注入变异 · 200 个体演化</i></p>

## 这是什么

你画（或让程序随机生成）一个字作为**始祖**，它会带着骨架与六个性状基因代代相传。
画布上同时有 200 个个体，按生态位着色：**楷 / 行 / 草 / 狂**。每一代都有新血混入，
所以族群不会塌缩成一个最优解——这是这件作品和所有"遗传算法做字体"-demo 的根本区别。

摄像头是可选的。开了之后，**你的手就是变异源**：

| 手的动作 | 变成什么 | 为什么不是同一个参数 |
| :--- | :--- | :--- |
| 手快（速度） | 变异**率** — 一代里有多少基因被动到 | 手抖才是"幅度"。分不开的话，每次快动作看起来都像心慌 |
| 手抖（残差） | 变异**幅度** — 每个基因跳多远 | 见 `js/signal.js` 顶部：速度必须从抖动里彻底扣除 |
| 突然停住 | 一次**突发变异** | 犹豫时甩笔的那一下；衰减很快，只落在那一两代上 |

## 运行

零构建、零依赖安装（除摄像头那条路要从 CDN 取 MediaPipe 的 wasm）：

```bash
python serve.py          # http://127.0.0.1:8020/
npm test                 # 8 个纯逻辑测试文件 / 225 项断言，无浏览器、无模型
```

滑块：变异基率、变异幅度、手抖联动、世代间隔、**移民比例**。
移民比例是目前唯一的多样性旋钮——它调的就是"每代有多少新血"。

## 一个字形基因组

```
genes    slant      倾侧（x 对 y 的错切）
         weight     笔画半宽（em 单位）—— 随笔数自动变细
         contrast   腹部粗细对比
         width      字面宽窄
         aspect     高矮
         flourish   末端出钩的强度
strokes  [ { pts: 7×[x,y],     骨架控制点（em box）
             ends: [起笔, 收笔], 0 = 折笔方切，1 = 藏锋出尖
             wob: 整数 } ]      可遗传的"笔性"噪声种子
```

渲染是一支笔，不是一根线：每笔按 `宽度剖面` 生成**变宽度的闭合轮廓**并填充，
所以起收笔有尖、腹部有肉、转折处不塌陷。见 `js/curve.js`。

## 三件被测出来、而不是想出来的事

写在前面是因为它们直接决定了现在的行为，不是实现细节。

1. **"快"不等于"抖"——但要真的做到，比听起来难。**
   先用"位置减去慢速滑动平均"算抖动：平均比移动的手慢一拍，240px/s 的直线扫过会
   留下 77px 残差，抖动直接顶到满量程——**一条直线被判为剧烈手抖**。
   改成减去*预测*位置（平均外推一个自身速度），直线才真的读到 0.000。
   而外推的时间常数必须用离散滞后 `step*(1-f)/f`，用 `posTau` 会差 5%，
   5% × 240px/s = 4px，又是满量程的三分之一。见 `test/signal.test.mjs`。

2. **创始个体不能用随机点。**
   随机控制点生成的是涂鸦，而覆盖度和凝聚度对涂鸦都给高分——选择压会直接绕过它们，
   族群在第一代就变成一团噪点。所以始祖是**拼**出来的：`archetype.js` 里
   横竖撇捺点折按 独体/上下/左右/包围/三叠 五种结构放进 5×5 格子里。

3. **墨量必须对着图定，不能对着数字定。**
   第一版单笔半宽 0.072em（14% 的 em），看着"有肉"，渲成接触印相一看：三十六个全是墨块，
   每个「点」都是一块圆饼。原因是 `fit()` 会把骨架连同笔宽一起放大——零点一 em 长的点被撑到八倍，
   笔也跟着粗了八倍。现在半宽 0.042em（8%，接近楷书横画的真实比例）、`fit` 倍数封顶 2.2、
   笔宽另有 0.055em 的硬上限。**所有"好不好看"的判断都在 `tools/plate.mjs` 出的图上做。**

4. **度量有同一个全局最优点。** 这是最重要的一条。
   覆盖/凝聚/平衡三个分量可以同时被同一种形状满足：一个紧凑、连通、居中、墨量约 30% 的团块。
   于是 40 代之后，八条被抽样的血脉**全部**收敛到同一个「习」——而多样性读数还写着 0.13。
   移民挡不住：新鲜始祖一两代内就被重新选掉。**一个会收敛的度量，配什么选择机制都会收敛。**

   两步解法，都在 `population.js` 和 `fitness.js` 里：
   - **按生态位分池配额**：每族有自己的名额、从自己的成员繁殖（同类相配），只有一小部分后代
     跨族。配额跟着艺术家的目标走，但每个生态位留 8% 下限——灭绝得费点力气。
   - **野性给目标而不是罚分**。罚分只能说"野要花钱"，目标说"这个族群应该住在行"，
     于是野性这一项才真的和其他项竞争，而不是一起输。实测四个目标各自都能撑起族群（120 体 60 代）：
     楷 81 / 行 62 / 草 75 / 狂 83；把一个 楷 主导的族群的目标改到狂，25 代内就变成 狂 主导。

5. **野性的退化解是原地涂改。** 目标机制一上来，狂草先长成了"一竖条挤在一起的乱线"。
   因为"每单位长度的转折量"最省力的最大化方式是把十几笔挤在一小块地方反复画。
   第一次修法是卡"总路径长度"——**没用**，涂改本身就能画出 2~3 em 的路径。
   第二次改成卡"路径长度 / 覆盖范围"，即走了多远对走了多长：一次果断的长撇是 0.8em 覆盖 2em 路径（0.4），
   涂改是 0.4em 覆盖 2.5em（0.16）。这一改，狂草才变成有撇有捺有钩的真草书。

| `js/fitness.js` | 覆盖 / 凝聚 / 平衡 / 野性、生态位、可行度闸门、**选择压与配额** |
| `js/population.js` | 200 个体、**按生态位分池的配额选择**、精英 + 子代 + 移民 + 补种、血缘记录 |

| `js/pose.js` | 唯一的落笔规则：食指伸直与否 |

| `tools/png.js` | 无依赖 PNG 编码 + 扫描线多边形填充（带解析覆盖率抗锯齿） |

## 诚实的边界

- **同一族内部仍然会收敛到一个形**。这是选择的本质，不是 bug：配额保证的是四个族共存，
  不是族内多样。族内的多样性要靠下一步（支系树 + 族内子配额）才有意图地处理。
- **字面率被 `fit` 封顶影响**：小于半 em 的骨架最多放大 2.2 倍，所以点、小笔画会比正常字小。
  这是有意的（字面率本来就该有变化），但它也意味着"极小的字"不能靠变大来赢。

## 边界

画面只在本机处理，不上传、不录制、不落盘（除你主动导出的 PNG）。
手势识别要下 MediaPipe 的手部模型（约 8MB，走 CDN）；不开摄像头也能玩，只是
变异只能由滑块决定。
